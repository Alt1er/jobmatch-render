# Розгортання JobMatch: GitHub + Render

Стратегія: **базове (basic) розгортання з безперервною доставкою (CI/CD)** — кожен `git push` у гілку `main` автоматично збирає й оновлює сайт на Render.
Платформа: **Render** (веб-сервіс Node.js + керована база PostgreSQL, безкоштовний рівень, HTTPS із коробки).

## 1. Завантажити код на GitHub

```bash
cd jobmatch
git init
git add .
git commit -m "JobMatch: перша версія"
git branch -M main
# створіть порожній репозиторій на github.com (кнопка New, без README) і вставте його адресу:
git remote add origin https://github.com/ВАШ_НІК/jobmatch.git
git push -u origin main
```

Файли `.env`, `node_modules`, `backend/.pgdata` та завантажені резюме в репозиторій не потрапляють (`.gitignore`).

## 2. Створити сайт на Render (через Blueprint)

1. Зареєструйтесь на https://render.com (можна через GitHub).
2. **New → Blueprint** → оберіть репозиторій `jobmatch` (дозвольте Render доступ до GitHub).
3. Render прочитає `render.yaml` і покаже два ресурси: веб-сервіс `jobmatch` та базу `jobmatch-db`. Натисніть **Apply**.
4. Зачекайте 3–6 хвилин, поки завершиться збірка (**Logs**). Статус стане **Live**.
5. Адреса сайту — вгорі сторінки сервісу, виду `https://jobmatch-xxxx.onrender.com`. Це і є посилання для здачі.

Усе потрібне налаштовується автоматично: `DATABASE_URL` (з бази), `JWT_SECRET` (випадковий), `AUTO_SEED=true` (вакансії й тестові акаунти при першому старті), таблиці створюються самі.

### Якщо Blueprint недоступний — вручну
- **New → PostgreSQL** (Free) → скопіюйте *Internal Database URL*.
- **New → Web Service** → репозиторій; Runtime `Node`; Build Command: `npm run render-build`; Start Command: `npm start`; Health Check Path: `/api/health`.
- Environment: `NODE_ENV=production`, `NODE_VERSION=20`, `DATABASE_URL=<Internal URL>`, `JWT_SECRET=<довгий випадковий рядок>`, `AUTO_SEED=true`.
- Якщо підключаєтесь до *External* URL (не внутрішнього) — додайте `DATABASE_SSL=true`.

## 3. Перевірка

- Відкрийте `https://ВАША-АДРЕСА.onrender.com/api/health` → `{"status":"ok"}`.
- Увійдіть: `candidate@jobmatch.ua` / `JobMatch#2026`, завантажте резюме з папки `samples/`, перегляньте відсотки збігу.
- Роботодавець: `hr@technova.com.ua` / `JobMatch#2026`.
- Адміністратор: `admin@jobmatch.ua` / `JmAdmin@2026` → **Адмін-панель** (звернення, стан системи).

> Якщо сайт уже був розгорнутий зі старими акаунтами (`candidate@demo.ua` тощо), після `git push` вони автоматично отримають нові адреси й паролі — нічого видаляти не потрібно.
> Щоб задати власний пароль адміністратора, додайте в **Environment** змінну `ADMIN_PASSWORD` **до** першого запуску нової версії.

## 4. Оновлення сайту (CD)

```bash
git add .
git commit -m "Що змінилось"
git push
```
Render сам побачить новий коміт і перезбере сайт.

## Обмеження безкоштовного плану Render (згадайте в звіті)

- Сервіс «засинає» після ~15 хв без запитів; перший запит після цього триває до хвилини.
- Файлова система тимчасова: **оригінали завантажених резюме (PDF/DOCX) зникають після перезапуску/оновлення**. Розпізнаний текст, навички й відсотки зберігаються в базі, тому підбір працює; тільки кнопка «завантажити оригінал» може повернути «файл не знайдено». Рішення — платний диск Render або S3-сховище.
- Безкоштовна база PostgreSQL на Render діє обмежений термін (зараз ~30 днів), потім її треба оновити/перенести — перевірте актуальні умови на render.com/pricing.
- Для публічного використання задайте власні `SEED_PASSWORD` / `ADMIN_PASSWORD` і вимкніть підказку на сторінці входу: `SHOW_TEST_ACCOUNTS=false`.

## Що писати в звіті (лабораторна №6)

- **Обрана стратегія:** базове розгортання + CI/CD через GitHub → Render. Обґрунтування: невеликий застосунок без потреби в нульовому простої; автоматизація зменшує ручні помилки; Render безкоштовний, дає HTTPS, керовану PostgreSQL і автодеплой із репозиторію.
- **Етапи (за теорією):** підготовка (збірка React, залежності, конфігурація `render.yaml`) → тестування (`npm test`, 10 наскрізних тестів) → розгортання (`git push`, збірка на Render, перевірка `/api/health`).
- **Результат:** працюючий сайт за публічним посиланням + репозиторій GitHub.
