# Історія змін JobMatch

Формат: [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), версії — [SemVer](https://semver.org/lang/uk/).

## [1.1.0] — 2026-11-19 · Технічне обслуговування (ЛР7)

### Безпека (профілактичне обслуговування)
- Замінено загальновідомий пароль `Demo1234!` і адреси `…@demo.ua` / `…demo` на нові тестові акаунти (`…@jobmatch.ua`, `…com.ua`).
- Старі акаунти у вже розгорнутій базі автоматично отримують нові адреси й пароль при старті (`db/maintenance.js`).
- Паролі задаються змінними середовища `SEED_PASSWORD`, `ADMIN_PASSWORD`; підказку на сторінці входу можна вимкнути (`SHOW_TEST_ACCOUNTS=false`).
- Обмеження частоти звернень (anti-spam), `trust proxy` для коректної IP-адреси за проксі Render.
- Dependabot і щотижневий `npm audit` у CI.

### Додано (удосконалювальне обслуговування)
- Сторінка **«Зворотний зв'язок»**: тип звернення, розділ сайту, пріоритет, оцінка 1–5, перегляд статусу й відповіді.
- Роль **адміністратора** та **адмін-панель**: стан сервера, статистика, звернення (статус, пріоритет, відповідь), журнал помилок.
- Версія застосунку у футері та в `/api/meta`.

### Змінено (коригувальне / адаптивне обслуговування)
- `/api/health` перевіряє з'єднання з базою і повертає `503`, якщо БД недоступна (Render перезапустить сервіс).
- Серверні помилки (HTTP 500) записуються в таблицю `error_log`.
- Схема БД оновлюється без втрати даних (`ALTER TABLE … DROP/ADD CONSTRAINT`).
- GitHub Actions: тести та збірка при кожному push.
- Тести: 10 → 13 сценаріїв.
